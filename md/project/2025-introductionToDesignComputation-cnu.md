
# 주제 : 데이터 기반 사회, AI 시대의 디자인 도구

소주제: 디자인에서의 데이터 활용 / 프로세스의 코드화 

내용: AI 시대 디자이너는 어떻게 도구를 확장하고 사고(디자인 프로세스)를 코드화할 수 있을까요? 이 강연에서는 컴퓨테이셔널 디자인의 개념부터 공간정보, 프로그래밍 사고, 그리고 AI를 활용한 디자인 프로세스까지, 21세기 데이터 기반 사회에서 디자이너가 알아야 하는 내용을 살펴봅니다. 

이남주 소장 / nj.namju@gmail.com 
NJS Lab & NJSTUDIO / https://namjulee.github.io/njs-lab-public/ 


1: 디자인 재료로서의 데이터와 컴퓨테이셔널 사고 

2: Vector & Raster 데이터의 이해, 그리고 컴퓨테이셔널 디자인 

3: 공간정보의 이산화, 디자인 데이터 구조와 알고리즘 

4: 연역적·귀납적 프로그래밍과 디자인 프로세스의 코드화 

5: AI, Machine Learning-aided Design 그리고 디자인 문제 인식과 기술 

6: https://namjulee.github.io/njs-lab-public/course
